---
name: reach-reinstall
description: Use when the student asks to reinstall rEach, to start over with a fresh copy, or to repair rEach by removing it and installing it again.
---
Reinstalling rEach is one command, and the student decides. You never delete rEach's folders, download the installer, or touch the student's work yourself.
Run `reach reinstall --harness <claude-code | codex | antigravity | hermes>`, naming the app you are running in (Codex: ask to run it outside the sandbox from the start, because it removes things outside the reach-work folder and downloads from GitHub). rEach fetches its installer first, so a failed download removes nothing. It then prints a question that lists what it will remove and what stays. Give it to the student word for word and stop. Never answer it yourself: only the student's own typed yes counts, and `--yes` is refused while rEach is enrolled and working.
After the student's yes, in their next message, run the same command again. rEach tells the course server, removes itself, installs the current stable release and runs its setup, then prints what setup said. Give the student anything setup says they must do themselves.
The student is not enrolled after a reinstall. Continue with INSTALL.md from the step after the install command, reading it from https://raw.githubusercontent.com/SteveBenner/rEach/stable/INSTALL.md at that moment, because the copy that came with the old install is gone. Setup prints a NEXT block: begin your next message to the student with the lines after "NEXT", copied exactly as printed.
If rEach prints that it was removed but the new copy could not be installed, give the student the prompt it shows, word for word, and tell them to paste it into a new chat in their AI app. Your own chat's hooks pointed at the old copy, so if your next command fails for that reason, tell the student to start a new chat and continue there.
Run it from a chat inside the reach-work folder, where rEach's hooks can hear the answer. If rEach says it cannot take a yes here, open that folder in the app and ask again, or have the student type `reach reinstall --harness <app>` in a terminal.
Add a choice only when the student asks for it: `--purge-checkpoint-mirror` (also delete the extra copies of their work files), `--no-receipts-copy`, `--purge-microbrain` (also delete the private memory rEach keeps in a hidden folder inside reach-work), `--no-teach`. `--delete-hermes-profile` and `--keep-workspace-files` do not work with a reinstall.
When `reach` will not start, follow UNINSTALL.md in the rEach repository to remove it, then the install prompt: install rEach from ZIP from github.com/SteveBenner/rEach.
Their work in reach-work (deliverables, extracurricular and everything else the student wrote) is never removed, and a copy of their receipts is saved to Downloads first. If they installed rEach with rplugin, run `rplugin uninstall reach` and `rplugin install` instead.
